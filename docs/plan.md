# Portfolio delivery plan pointer

This repository does not maintain a second dispatchable portfolio task graph.
The authoritative cross-project source is
[Foundry docs/portfolio-plan.md](https://github.com/sirerun/foundry/blob/main/docs/portfolio-plan.md)
(plan ID `foundry:portfolio`, authority `foundry:repository`). It is an ordinary
versioned planning artifact, not a replacement for canonical runtime lifecycle
owners, existing source implementation plans or active claims.

Use this repository's [RFC](rfc/rfc-001.md) and
[accepted boundary ADR](adr/001-foundry-capability-boundary.md) as requirements.
Cross-repository links identify the coordinated documentation destination; a
link alone does not establish that its candidate has landed or been deployed.
No task admission, implementation, provisioning, spend, migration, retirement
or production promotion is authorized by this pointer.
